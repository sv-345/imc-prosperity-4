# Escalations

Append-only log of issues requiring Director attention.

Format:

```
[ISO timestamp] — [originating role]
Issue: <one paragraph>
Blocking: <what work cannot proceed without resolution>
Suggested resolution (optional): <if originator has a suggestion>
```

Director resolution appended under original entry:

```
Director resolution — [ISO timestamp]
Decision: <specific instruction>
Routed to: <which role implements>
```
