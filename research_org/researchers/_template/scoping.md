# Researcher Scoping (template)

**Owner:** Researcher for this project (writes during Phase 0 / initial scoping).
**Readers:** Director, Allocator, Skeptic.

Scopes the project's angle, deliverable, and effort estimate. Used by
Director to fund and by Allocator to detect runaway projects
(>150 % of scoped time triggers auto-escalation).

Format:

```
Project: [name]
Angle: <one paragraph on the specific microstructure question>
Deliverable: <what Phase C spec will contain if successful>
Effort estimate: <hours per phase>
Success probability: <calibrated guess>
Data dependencies: <files, MC outputs, server logs>
Non-goals: <adjacent questions this project will NOT answer>
```
